数据收集隐私政策

适用于 www.politicshub.it 的数据收集

本文为参考译文，仅意大利语版本具有法律效力。阅读意大利语版本。

本隐私政策旨在根据第 196/03 号立法令（《个人数据保护法》）第 13 条及欧盟第 679/2016 号条例（“GDPR”），告知用户/访问者本网站在处理个人数据方面的管理方式。

本声明适用于访问 Politics Hub 协会网站、并通过 www.politicshub.it 使用其网络服务的人士。

www.politicshub.it 网站归 Politics Hub 协会所有，协会保证遵守个人数据保护相关法规（第 196/03 号立法令及欧盟第 679/2016 号条例）。

请用户/访问者在填写网站上的任何电子表单之前，仔细阅读本隐私政策。

处理的数据类型及处理目的

在使用/浏览本网站时，您可以通过在电子表单中填写个人数据来使用相关服务；我们仅会为与所请求和使用的服务严格相关的目的处理这些数据。以下是使用本网站时所处理的数据类型。

浏览数据

本网站运行所使用的计算机系统和软件程序在正常浏览过程中会获取一些个人数据，这些数据的传输是使用互联网通信协议时所固有的。此类数据包括：

  • IP 地址；
  • URI（统一资源标识符）地址；
  • 用户/访问者使用的操作系统；
  • 用户/访问者计算机环境的其他参数。

这些数据在保持用户匿名的前提下用于统计本网站的使用情况，但在发生针对本网站的计算机犯罪时，也可能被用于追究责任。

用户/访问者自愿提供的数据

访问本网站的用户/访问者可以提交个人数据以使用某些服务，例如通过电子邮件发送请求、联系请求或服务请求；这意味着 Politics Hub 协会将获取发送者的地址和/或其他个人数据，这些数据仅用于回复请求或提供所请求的服务。

仅在满足用户/访问者请求所必需时，才会将其提供的个人数据告知第三方。

Cookie

在浏览本网站时，您的电脑/设备上可能会安装一些 Cookie；这些 Cookie 仅为技术性 Cookie，用于改善您的浏览体验。

处理方式

本网站托管于 GitHub 的静态托管服务 GitHub Pages。通过网站表单提供的数据由所使用服务的专项声明中列明的系统处理，并存储在安全的服务器上。

数据控制者

与上述网站网络服务相关的数据处理在 Politics Hub 协会注册地址（Viale Gorizia, 44, Legnano (MI)）进行。

因使用本网站网络服务而产生的任何信息/数据均不会被告知他人或公开传播。请求资料的用户/访问者所提供的个人数据仅用于提供所请求的服务，且仅在为此目的所必需时才会告知第三方。

数据主体的权利

个人数据所涉及的人士有权（根据第 196/03 号立法令第 7 条）随时确认其数据是否存在于我们的档案中，核实其准确性，并要求更新或删除。请将请求发送至数据控制者：info@politicshub.it。

我们保留随时修改本隐私声明的权利，请经常查看。修改和说明自在网站上发布之时起生效。如本声明发生重大变更，我们将通知您，以便您了解我们收集哪些信息、如何使用这些信息，以及在何种情况下使用和/或披露这些信息。
