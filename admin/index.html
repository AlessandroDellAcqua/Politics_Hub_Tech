Accesso

Il pannello scrive direttamente nel repository GitHub del sito. Serve un token personale (fine-grained) con permesso Contents: Read and write sul solo repository del sito. Il token resta salvato solo su questo computer.

Come crearlo: GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token → Repository access: solo il repo del sito → Permissions → Contents: Read and write.

Pubblica un nuovo evento

Se c'è già un evento pubblicato, verrà spostato automaticamente nell'archivio interno e sostituito da questo.

Se vuoto e il sito ha i moduli attivi, il bottone "Iscriviti" porta al modulo integrato con biglietti QR. Ricorda di aggiungere la riga dell'evento nella scheda Eventi del Google Sheet (usa l'ID mostrato sopra dopo la pubblicazione).

Rimuovi l'evento corrente

L'evento passa nell'archivio interno e il sito mostrerà "nessun evento in programma", con l'indicazione del mese stimato del prossimo evento.

Nuovo articolo del Poligono

Il nuovo articolo comparirà per primo nella pagina del Poligono. Quello attualmente in evidenza scenderà automaticamente nell'archivio "Articoli precedenti" — non devi fare nulla.
